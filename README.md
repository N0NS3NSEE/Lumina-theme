# Lumina — SillyTavern UI Theme

A sleek, modern, animated theme for SillyTavern. Dark glass panels,
sapphire accents, rounded corners, and the Inter typeface.

## Install (as extension)
1. Copy this repo's URL.
2. In SillyTavern: Extensions → Install Extension → paste URL → Install.
3. Reload. The theme CSS applies automatically.

## Install (quick — theme JSON)
If you just want the colors without the extension:
Settings → Theme → custom CSS box → paste the contents of style.css.

## Tweak
All palette values live in the `:root` block of style.css.
Change `--lumina-accent` to recolor the whole UI.
